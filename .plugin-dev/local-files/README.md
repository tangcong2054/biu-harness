# 本地文件（local-files）

在 Biu 里像 VS Code 一样打开**你电脑上的**文件和文件夹。文件内容只在浏览器里读写，不经过服务器。

## 入口

- **拖进页面**：把文件或文件夹拖到页面正文里，落点会生成一个「本地文件」块（纯图片仍走原来的图片上传）。
- **斜杠插入**：在页面里输入 `/本地文件`（或 `/vscode`、`/file`），再点「打开文件夹 / 打开文件」。
- **会话右侧栏**：右侧栏「本地文件」tab，显示本浏览器里打开过的所有文件夹 / 文件。
- 块头部可以切到**右侧栏**或**全屏**，全屏就是完整的类 VS Code 工作台。

## 能力

- 资源管理器（默认隐藏 `node_modules` / `.git` 等，可切换显示）、多标签、新建文件 / 文件夹、删除
- 代码编辑器：CodeMirror 6，常见语言语法高亮、搜索（Ctrl/⌘+F）、Ctrl/⌘+S 保存
- 编辑区或 Markdown 预览选中文字后按 Ctrl/⌘+L，或点击「加入对话」，将选区加入 agent 对话草稿（由用户确认发送）。携带 `local-files` 插件身份、本地根、文件路径与未保存标记；源码选区带行号，Markdown 预览选区明确标记为渲染文本，不伪造源码行号。HTML 仍需切到「编辑」模式；单次选区最多 100KB。提交对话后，选区会进入服务端和模型上下文。
- Markdown 渲染使用 DOMPurify 严格白名单去除脚本、事件属性、内嵌窗口、表单及文件提供的样式，再在本页显示以支持选区交互；原始 HTML 继续使用不允许脚本或同源访问的沙箱 iframe。
- 预览：Markdown（预览 / 编辑切换）、HTML（沙箱预览）、图片、PDF、音视频；二进制文件可下载
- 未保存的修改会作为草稿存在浏览器里，刷新不丢
- 文件在外部被修改时自动同步；若这里也有未保存修改，会提示你选择

## 浏览器差异

| | Chrome / Edge | Firefox / Safari |
|---|---|---|
| 选择 / 拖入 | 可写句柄 | 只读快照 |
| 保存 | 直接写回原文件 | 下载为新文件 |
| 刷新页面后 | 点一次「恢复访问」继续 | 自动从本浏览器 IndexedDB 恢复只读文件副本 |

只读文件先开放浏览，再在后台逐个读取并保存副本，不等待整个文件夹保存完成。界面显示进度；只有出现「副本已保存，可刷新恢复」才保证本次副本已经提交到 IndexedDB。未完成或保存失败时刷新会触发浏览器离开提醒，保存失败可重试；浏览器可能限制提醒的显示。

副本按文件分条存储（IndexedDB `files` 表），根记录只保存目录结构；刷新恢复时只读取目录，打开哪个文件才读取哪个文件的内容。旧版本整体保存的副本会在首次恢复时，在后台迁移为新格式。

Firefox 的「打开文件夹」在选择窗口关闭后，会先由浏览器枚举整个文件夹（包括 `node_modules` 等，插件之后才会把它们过滤掉），枚举完成后页面才会收到文件。枚举期间界面会显示「正在读取…」。大文件夹建议直接拖入，拖入时会跳过这些目录。

只读副本保留选择时的内容，不自动同步磁盘上的后续修改。选择大文件夹时浏览器本身的文件枚举仍可能较慢。清除站点数据、隐私模式退出或浏览器清理存储时可能丢失；它不是文件备份。

## 共享与隐私

块里只存文件名、路径等元信息。本地文件只在添加它的那个浏览器里能打开，其他人看到的是占位提示。
点块头部的「保存快照到页面」，才会把**当前已保存的文件内容**上传为页面附件（≤10MB），能看到页面的人都可以查看这份只读快照。

## agent（uiActions）

工作台注册 `kind=workbench` 目标：`list_roots`、`list_dir`、`read_file`、`open_file`、`save_active`、`write_file`。
`write_file` 风险为 `destructive`，每次都需要用户确认；只读快照不能写。

## 示例写法

插入一个空的本地文件块（打开后再选择文件夹 / 文件）：

:::pageBlock {kind=local-file plugin=local-files}
{
  "title": "本地文件",
  "height": 460
}
:::

已关联的块（`rootId` 由浏览器生成，只在添加者的浏览器里有效；`snapshot` 可选）：

:::pageBlock {kind=local-file plugin=local-files}
{
  "title": "my-project",
  "rootId": "lf_0123456789abcdef",
  "rootName": "my-project",
  "rootKind": "directory",
  "path": "src/index.ts",
  "height": 460
}
:::
